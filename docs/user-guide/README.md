# NST Connect user guides

| Guide | For | What it covers |
| --- | --- | --- |
| [Student guide](student-guide.md) | Students | Sign-up, raising a ticket (what is required and optional), statuses, closing, feedback, reopening, what to expect |
| [POC guide](poc-guide.md) | L1, L2, L3 staff | Queue, replying, solving, closing, escalating, the time limit and automatic escalation, leave, analytics, team management |
| [Admin guide](admin-guide.md) | Super Admin | Categories and topics, building teams, the escalation time, analytics, notes, checks, limits |

These describe what the app does today, based on the code. If behaviour changes (for example notifications are added), update the guides.
